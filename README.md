# ReadMe.md
Лабораторна робота №2: Побудова фракталів (C++)
Реалізація класичних рекурсивних алгоритмів побудови геометричних фракталів мовою C++ з предмету «Структури даних».
Структура репозиторію
-	Task1_Sierpinski_Triangle/main.cpp — Трикутник Серпінського (рекурсивний пошук середніх ліній трикутника).
-	Task2_Sierpinski_Carpet/main.cpp — Килим Серпінського (поділ квадрата на 9 частин із зафарбуванням центрального та рекурсивним обходом 8 сусідніх блоків).
-	Task3_Pythagoras_Tree_Branches/main.cpp — Дерево Піфагора з гілок (лінійне рекурсивне гілкування під кутами $\pi/4$ та $-\pi/6$).
-	Task4_Cantor_Set/main.cpp — Множина Кантора (поділ відрізка на три частини з відкиданням центральної третини).
-	Task5_Pythagoras_Tree_Squares/main.cpp — Класичне дерево Піфагора з нахилених квадратів.
-	Task6_Koch_Snowflake/main.cpp — Крива Коха та сніжинка Коха.
-	All_In_One_Win32/main.cpp — Універсальна версія з інтерактивним меню всіх 6 завдань через стандартний Windows GDI (<windows.h>), яка компілюється у VS Code (MinGW) та Visual Studio без встановлення додаткових бібліотек.
